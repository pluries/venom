name: Quickstart suite
testcases:
  - name: say hello
    steps:
      - type: exec
        script: echo "hello venom"
        assertions:
          - result.systemout ShouldContainSubstring hello
          - result.code ShouldEqual 0

Why this fork

Venom is a good tool that needed an owner. This fork keeps it maintained, upgrades what it stands on, adds executors, and ships releases you can verify.

Maintained

Someone is on it

213 commits since the previous release. Every change passes lint, tests and a SonarQube gate on new code before it is merged.

Upgraded

Current foundations

Built with Go 1.27. Known vulnerabilities in the standard library and in dependencies are fixed as they are found, and a vulnerability scan runs on every build.

New executors

More to test

mcp tests Model Context Protocol servers over stdio or HTTP. mobile drives Android and iOS apps through Appium. The web executor now runs on Playwright.

Faster

Measured, not promised

A run that reuses a large captured response across steps is 13× faster and uses about six times less memory. --parallel runs test files at once: 3.4× at 4 workers and 5.6× at 8, on files that spend their time waiting.

Secure by default

Checked, not trusted

One TLS layer for every executor, SSH host keys always verified, and no self-update that downloads a binary without checking it.

Signed releases

Verify what you run

Executables for Linux, macOS, Windows, FreeBSD and OpenBSD, a signed checksum list, and a container image at ghcr.io/pluries/venom.
