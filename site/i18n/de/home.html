Beschreiben Sie eine Test-Suite in einer Datei. Venom führt jeden Schritt aus, prüft jede Assertion und zeigt Ihnen, welche Zeile fehlgeschlagen ist.

Schnellstart Zur Dokumentation Unabhängiger Fork von ovh/venom · Apache-2.0
site/examples/quickstart.yml
name: Quickstart suite
testcases:
  - name: say hello
    steps:
      - type: exec
        script: echo "hello venom"
        assertions:
          - result.systemout ShouldContainSubstring hello
          - result.code ShouldEqual 0
Ausgabe des Laufs
$ venom run site/examples/quickstart.yml
 • Quickstart suite (site/examples/quickstart.yml)
 	• say-hello PASS
final status: PASS

Über diesen Fork

Venom ist ein solides Werkzeug, und dieser Fork hält es in Bewegung: gepflegt, auf dem neuesten Stand, mit neuen Executors und Releases, die sich überprüfen lassen.

Gepflegt

Jemand kümmert sich

213 Commits seit dem vorherigen Release. Jede Änderung besteht Lint, Tests und ein SonarQube-Gate für neuen Code, bevor sie übernommen wird.

Erneuert

Aktuelle Grundlagen

Gebaut mit Go 1.27. Bekannte Schwachstellen in der Standardbibliothek und in Abhängigkeiten werden behoben, sobald sie auftauchen, und bei jedem Build läuft ein Schwachstellen-Scan.

Neue Executors

Mehr zu testen

mcp testet Model-Context-Protocol-Server über stdio oder HTTP. mobile steuert Android- und iOS-Apps über Appium. Der web-Executor läuft jetzt auf Playwright.

Schneller

Gemessen, nicht versprochen

Ein Lauf, der eine große aufgezeichnete Antwort über mehrere Schritte wiederverwendet, ist 13× schneller und braucht etwa sechsmal weniger Speicher. --parallel führt Testdateien gleichzeitig aus: 3.4× mit 4 Workern und 5.6× mit 8, bei Dateien, die meist warten.

Sicher von Haus aus

Geprüft, nicht vertraut

Eine TLS-Schicht für jeden Executor, SSH-Host-Keys werden immer verifiziert, und es gibt kein Selbst-Update, das eine Binärdatei ungeprüft herunterlädt.

Signierte Releases

Prüfen, was Sie ausführen

Programme für Linux, macOS, Windows, FreeBSD und OpenBSD, eine signierte Prüfsummenliste und ein Container-Image unter ghcr.io/pluries/venom.
