Venom ist ein Kommandozeilenwerkzeug, das in YAML geschriebene Integrationstests ausführt. Eine Test-Suite listet Schritte auf. Jeder Schritt wird von einem Executor ausgeführt, und sein Ergebnis wird mit Assertions geprüft.

Diese Website dokumentiert einen unabhängigen Fork von [ovh/venom](https://github.com/ovh/venom). Der Fork hat eigene Releases und eigene Änderungen.

Wie es weitergeht:

- [Schnellstart](quickstart.html): venom installieren, eine Suite schreiben und ausführen.
- [Überblick](overview.html): was venom leistet und wie eine Suite aufgebaut ist.
- [Konzepte](testsuites.html): Test-Suites, Executors und Variablen.
- [Anleitungen](cli-usage.html): Kommandozeile, Berichte und Continuous Integration.
- [Executors](executors-concept.html): eine Seite für jedes Protokoll, das venom testen kann.
- [Referenz](assertions.html): Assertions, eingebaute Variablen und Beiträge zum Projekt.
