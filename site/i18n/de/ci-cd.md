# venom in CI/CD-Pipelines verwenden {#use-venom-in-cicd-pipelines}

Venom lässt sich in der Entwicklungsumgebung oder auf Ihrem CI-Server verwenden.
Damit die Ausgabe von venom korrekt dargestellt wird, müssen Sie vor dem Start von venom wahrscheinlich die Umgebungsvariable `IS_TTY=true` exportieren.
