site/examples/quickstart.yml
name: Quickstart suite
testcases:
  - name: say hello
    steps:
      - type: exec
        script: echo "hello venom"
        assertions:
          - result.systemout ShouldContainSubstring hello
          - result.code ShouldEqual 0

Informazioni su questo fork

Venom è uno strumento solido, e questo fork lo fa andare avanti: curato, sempre aggiornato, con nuovi executor e release che puoi verificare.

Manutenuto

Qualcuno se ne occupa

213 commit dalla release precedente. Ogni modifica supera lint, test e un quality gate SonarQube sul codice nuovo prima di essere integrata.

Aggiornato

Basi attuali

Compilato con Go 1.27. Le vulnerabilità note nella libreria standard e nelle dipendenze vengono corrette man mano che emergono, e a ogni build viene eseguita una scansione delle vulnerabilità.

Nuovi executor

Più cose da testare

mcp testa i server Model Context Protocol su stdio o HTTP. mobile pilota le app Android e iOS tramite Appium. L'executor web ora funziona con Playwright.

Più veloce

Misurato, non promesso

Un'esecuzione che riutilizza tra più step una grande risposta acquisita è 13× più veloce e usa circa sei volte meno memoria. --parallel esegue più file di test contemporaneamente: 3.4× con 4 worker e 5.6× con 8, su file che passano il tempo in attesa.

Sicuro per impostazione predefinita

Verificato, non dato per scontato

Un unico livello TLS per ogni executor, chiavi host SSH sempre verificate e nessun aggiornamento automatico che scarichi un binario senza controllarlo.

Release firmate

Verifica ciò che esegui

Eseguibili per Linux, macOS, Windows, FreeBSD e OpenBSD, un elenco di checksum firmato e un'immagine container disponibile in ghcr.io/pluries/venom.
