# Usare venom nelle pipeline CI/CD {#use-venom-in-cicd-pipelines}

Venom si può usare in un ambiente di sviluppo o sul tuo server CI.
Per mostrare correttamente l'output di venom, probabilmente dovrai esportare la variabile d'ambiente `IS_TTY=true` prima di eseguire venom.
