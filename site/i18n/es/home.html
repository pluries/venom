Quickstart Leer la documentación Fork independiente de ovh/venom · Apache-2.0
site/examples/quickstart.yml
name: Quickstart suite
testcases:
  - name: say hello
    steps:
      - type: exec
        script: echo "hello venom"
        assertions:
          - result.systemout ShouldContainSubstring hello
          - result.code ShouldEqual 0

Sobre este fork

Venom es una herramienta sólida, y este fork la mantiene en marcha: cuidada, al día, con nuevos executors y versiones que usted puede verificar.

Mantenido

Alguien se ocupa de él

213 commits desde la versión anterior. Cada cambio supera el análisis estático, las pruebas y una puerta de calidad de SonarQube sobre el código nuevo antes de integrarse.

Actualizado

Bases actuales

Compilado con Go 1.27. Las vulnerabilidades conocidas de la biblioteca estándar y de las dependencias se corrigen en cuanto se detectan, y un análisis de vulnerabilidades se ejecuta en cada compilación.

Nuevos executors

Más cosas que probar

mcp prueba servidores de Model Context Protocol por stdio o HTTP. mobile controla aplicaciones Android e iOS mediante Appium. El executor web funciona ahora con Playwright.

Más rápido

Medido, no prometido

Una ejecución que reutiliza una respuesta capturada de gran tamaño en varios pasos es 13× más rápida y usa unas seis veces menos memoria. --parallel ejecuta varios archivos de prueba a la vez: 3.4× con 4 workers y 5.6× con 8, en archivos que pasan su tiempo esperando.

Seguro por defecto

Comprobado, no supuesto

Una única capa TLS para todos los executors, claves de host SSH siempre verificadas y ninguna autoactualización que descargue un binario sin comprobarlo.

Versiones firmadas

Verifique lo que ejecuta

Ejecutables para Linux, macOS, Windows, FreeBSD y OpenBSD, una lista de sumas de verificación firmada y una imagen de contenedor en ghcr.io/pluries/venom.
