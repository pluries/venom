Décrivez une suite de tests dans un fichier. Venom exécute chaque étape, vérifie chaque assertion et vous dit quelle ligne a échoué.

Quickstart Lire la documentation Fork indépendant de ovh/venom · Apache-2.0
site/examples/quickstart.yml
name: Quickstart suite
testcases:
  - name: say hello
    steps:
      - type: exec
        script: echo "hello venom"
        assertions:
          - result.systemout ShouldContainSubstring hello
          - result.code ShouldEqual 0
Résultat de l'exécution
$ venom run site/examples/quickstart.yml
 • Quickstart suite (site/examples/quickstart.yml)
 	• say-hello PASS

À propos de ce fork

Venom est un outil solide, et ce fork le fait avancer : il est maintenu, tenu à jour, avec de nouveaux executors et des versions que vous pouvez vérifier.

Maintenu

Quelqu'un s'en occupe

213 commits depuis la version précédente. Chaque modification passe le lint, les tests et une barrière SonarQube sur le code nouveau avant d'être fusionnée.

À jour

Des fondations récentes

Compilé avec Go 1.27. Les vulnérabilités connues de la bibliothèque standard et des dépendances sont corrigées dès leur découverte, et une analyse de vulnérabilités s'exécute à chaque build.

Nouveaux executors

Plus de choses à tester

mcp teste les serveurs Model Context Protocol via stdio ou HTTP. mobile pilote des applications Android et iOS avec Appium. L'executor web repose désormais sur Playwright.

Plus rapide

Mesuré, pas promis

Une exécution qui réutilise d'une étape à l'autre une grande réponse capturée est 13× plus rapide et consomme environ six fois moins de mémoire. --parallel exécute plusieurs fichiers de test à la fois : 3.4× avec 4 workers et 5.6× avec 8, sur des fichiers qui passent leur temps à attendre.

Sécurisé par défaut

Vérifié, pas supposé

Une seule couche TLS pour tous les executors, des clés d'hôte SSH toujours vérifiées, et aucune mise à jour automatique qui télécharge un binaire sans le contrôler.
