# Utiliser venom dans des pipelines CI/CD {#use-venom-in-cicd-pipelines}

Venom peut être utilisé dans un environnement de développement ou sur votre serveur de CI.
Pour afficher correctement la sortie de venom, vous devrez probablement exporter la variable d'environnement `IS_TTY=true` avant de lancer venom.
