在一个文件里描述测试套件。Venom 运行每个步骤，检查每条断言，并告诉您哪一行失败了。

快速入门 阅读文档 ovh/venom 的独立分支 · Apache-2.0
site/examples/quickstart.yml
name: Quickstart suite
testcases:
  - name: say hello
    steps:
      - type: exec
        script: echo "hello venom"
        assertions:
          - result.systemout ShouldContainSubstring hello
          - result.code ShouldEqual 0
运行输出
$ venom run site/examples/quickstart.yml
 • Quickstart suite (site/examples/quickstart.yml)
 	• say-hello PASS
final status: PASS

关于这个分支

Venom 是一款扎实可靠的工具，这个分支让它继续向前：持续维护，保持更新，增加新的 executor，并发布可以验证的版本。

持续维护

有人在负责

自上一个版本以来共有 213 次提交。每项改动在合并之前，都要通过 lint、测试以及针对新代码的 SonarQube 质量门禁。

已经升级

当前的底层

使用 Go 1.27 构建。标准库和依赖中已知的漏洞一经发现就会修复，每次构建都会运行漏洞扫描。

新 executor

可测试的更多

mcp 通过 stdio 或 HTTP 测试 Model Context Protocol 服务器。mobile 通过 Appium 驱动 Android 和 iOS 应用。web executor 现在基于 Playwright 运行。

更快

有实测，不是承诺

在多个步骤间复用大型已捕获响应的运行，速度提高 13×，内存占用约为原来的六分之一。--parallel 可同时运行多个测试文件：对大部分时间都在等待的文件，4 个并行任务时提速 3.4×，8 个时提速 5.6×。

默认安全

经过检查，而非盲目信任

所有 executor 共用一套 TLS 层，SSH 主机密钥始终经过验证，也没有下载二进制文件却不加校验的自更新功能。

签名发布

验证您运行的内容

提供适用于 Linux、macOS、Windows、FreeBSD 和 OpenBSD 的可执行文件、带签名的校验和清单，以及位于 ghcr.io/pluries/venom 的容器镜像。
